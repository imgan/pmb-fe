# Project Brief: Academic Excellence Portal (PMB System)

## Project Overview
The Academic Excellence Portal is a comprehensive digital solution for managing the New Student Admission (Penerimaan Mahasiswa Baru - PMB) process. It serves two primary audiences: prospective students seeking to join the university and administrative staff responsible for reviewing applications and managing the intake cycle.

## Core Objectives
- **Streamline Admissions**: Provide a seamless, step-by-step registration process for applicants.
- **Data Centralization**: Create a unified dashboard for administrators to monitor application trends and manage candidate data.
- **Professional Branding**: Establish trust through a cohesive, high-fidelity visual identity that reflects institutional prestige.

## Target Audience
1. **Prospective Students**: Tech-savvy individuals looking for a clear, frictionless way to apply to university programs.
2. **Admissions Administrators**: Staff members who need efficient tools for data entry, document verification, and status management (CRUD operations).

## Key Features & Screens
### 1. Student-Facing Landing Page
- **Purpose**: Brand positioning and entry point.
- **Features**: Hero section with "Apply Now" CTA, program highlights, and institutional value propositions.

### 2. Multi-Step Registration Form
- **Purpose**: Data collection from applicants.
- **Sections**: 
    - Personal Information (Name, ID, Contact).
    - Academic History (Previous school, GPA).
    - Program Selection (Choosing desired majors).

### 3. Admin Management Dashboard
- **Purpose**: High-level oversight and data management.
- **Features**:
    - Statistical cards (Total applicants, verified, pending).
    - Applicant table with search and filtering capabilities.
    - Quick actions for record management (View, Edit, Delete).

### 4. Applicant Detail & Review
- **Purpose**: Decision-making and verification.
- **Features**: 
    - Full profile view.
    - Document preview (ID cards, transcripts).
    - Status update controls (Approve/Reject) with internal notes.

## Design Language
- **Theme**: Academic Excellence (Professional, Trustworthy, Modern).
- **Color Palette**: Deep Navy (#1b365d) as the primary brand color, supported by clean surfaces and clear status indicators (Success/Warning/Error).
- **Typography**: Inter (Clean, sans-serif for high readability).
- **Components**: Rounded corners (4px), subtle shadows, and a consistent grid system.

## Technical Scope
- **Frontend**: Responsive HTML/CSS using Tailwind CSS for layout and styling.
- **Architecture**: Separated Admin and Public views with shared component patterns for navigation and branding.
